### Fixed

- When two OmC Native or Codex hosts start against the same home at once (for example a desktop app's primary engine and its pre-warmed spare), the one that finds the other already migrating the configuration no longer shows a "Configuration migration is already running" warning; the other host finishes the migration. A stale lock, a damaged migration journal or a real migration failure still warns.
