### Changed

- A task host now carries out a Stop, Resume or cancel that another omc process of the same user hands it for a child the host is running, through a small request file in the task store, instead of leaving that child untouched. Nothing sends such a request until the requesting half lands; `task.control_channel: false` turns the channel off. ([#12371](https://github.com/code-yeongyu/oh-my-cybersecurity/pull/12371), part of [#12349](https://github.com/code-yeongyu/oh-my-cybersecurity/issues/12349))
